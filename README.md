# 窥窗（KanWindow）

> 一个免费的 macOS 原生悬浮窗小工具：**多组网址**，每组一个悬浮窗，组内塞任意多个网站（豆包 / DeepSeek / ChatGPT Web / 任何网页），**⌥⌘D/E 一键在组内切站**。顶栏点一下即呼出，随用随走。
>
> 完全开源、无需登录、不收集数据。不依赖 Hammerspoon / Electron —— 纯 Swift + AppKit + WKWebView 原生实现。

## 🪟 分组机制（核心）

- **网址组**：一个组 = 一个悬浮窗。组里放**多个网址**。
- **切换至某组**（顶栏右键菜单，或给它配的快捷键）→ 该组成为“当前组”并呼出；之后 **⌥Space / 顶栏左键** 呼出的就是这一组。
- 组内用 **⌥⌘D（下一个）/ ⌥⌘E（上一个）** 在各网址间来回切，窗口标题显示「组名 · 站点名」，各站登录/会话互不影响。
- 默认配置：一个「AI 助手」组，含豆包、DeepSeek —— 装完就能 D/E 换着用。

## ⌨️ 快捷键（统一可配）

设置里有一张**全局快捷键表**（点＋添加、选中后录按键），每个快捷键绑定一个“功能”：

| 功能 | 说明 |
|---|---|
| 显示/隐藏当前组 | ⌥Space（默认） |
| 组内下一个网址 / 上一个网址 | ⌥⌘D / ⌥⌘E（默认） |
| 切换下一个组 / 上一个组 | 循环切换哪个组是“当前组” |
| 切换至「某组」 | 直接切到指定组并呼出 |
| 刷新当前浮窗 | 重载当前页面 |

固定的还有：**顶栏左键** = 呼出/收起（不弹菜单，不卡）；**⌘,** = 设置；**⌘C/⌘V/⌘X/⌘A** = 文本框编辑（内置编辑菜单）。

> 状态栏：**左键单击** = 呼出 / 收起当前组；**右键** = 菜单（切换至各组、显示全部组、隐藏全部组、设置、退出）。菜单每次现做新的一份再弹出，不会在跟踪中改菜单导致卡死。

## ✨ 其它特性

- ⏱ **自动关闭（不是隐藏）**：全局默认 15 分钟、每组可单独覆盖；浮窗闲置满 N 分钟会**彻底关闭该悬浮窗并释放网页内存**（不是只隐藏），需要时用快捷键再呼出，回到原位置、原网站（重新加载）。窗口内任何点击/滚动/输入会续时；设 0 = 不自动关闭。
- 🎛 **设置面板**（状态栏右键 → 设置 或窗口内 ⌘,）：三个“框”——**网址组**（名称/启停/自动关闭）、**组内网址**（未选中组时整块置灰，选中外层组才可编辑其网址）、**全局快捷键**（＋/− 加删、选功能、录按键）。另有导入/导出 JSON、恢复默认。
- 📐 **记忆位置与尺寸**：每组独立记住上次拖到哪、多大；组内自动记住停在哪一站，重开回到原站。
- 🎯 **焦点位置记忆**：打开弹窗自动回到上次网页内的焦点位置（如输入框——直接打字即可输入）和滚动位置；按快捷键收起弹窗时，自动把系统焦点还给打开弹窗前正在使用的那个 App，无需手动点击原窗口就能继续操作。
- 🧐 **B站极简搜索（他律模式）**：「娱乐」组默认打开「B站极简搜索」——页面上只有搜索框，无推荐、无推送、无弹幕；结果列表只显示标题、播放量、发布时间、UP主；点进视频只有播放画面＋评论区。页面与数据请求由 App 内置的本地代理（127.0.0.1:9327）提供，不依赖第三方扩展。
- 📋 **粘贴可用**：内置标准「编辑」菜单，WebView 文本框 ⌘V 正常。
- 🔍 **页面缩放**：⌘+ / ⌘- / ⌘0 放大、缩小、实际大小，作用于当前浮窗（对 B 站这类“横屏网页”很有用）；触控板也能双指缩放。
- 🧭 **站内跳转**：新标签页/新窗口式的链接（如 B 站的视频、动态）会在**当前浮窗内直接打开**，不再点了没反应。
- 🥤 **轻量**：原生 App；组未打开不占网页进程。
- 🔔 **常驻状态栏**：无 Dock 图标。
- 🎨 **原创图标**：App 图标 + 顶栏模板图标由纯几何 SVG 设计（源文件 `Resources/*.svg` 在仓库），简明表达“可悬浮弹出的网页小窗”，无任何版权风险；亮/暗菜单栏都清晰。

## 🖥 环境要求

- macOS 13.0+（Apple Silicon / Intel 均可）

```bash
xcode-select --install
```

## 📦 构建 & 安装

```bash
git clone https://github.com/MiaoArtist/KanWindow.git KanWindow
cd KanWindow
./scripts/build.sh            # 构建到 build/窥窗.app
./scripts/build.sh install    # 复制到 /Applications
open "/Applications/窥窗.app"
```

发布包：`窥窗-*.zip`（或 Release 里的 `KanWindow-v*.zip`），解压拖进「应用程序」即可。

### 📡 首次授权（一次性）

全局快捷键需要「辅助功能」权限：
1. 弹窗里点「打开系统设置」→ 隐私与安全性 → 辅助功能；
2. 勾选「窥窗」；约 2 秒后自动启用（状态栏图标闪 ✓）。
> 未授权也能用：点顶栏图标或右键菜单都能呼出浮窗。

## 🎛 设置面板速览（三个“框”）

- **① 网址组**：左列表可勾选**启用/停用**；右侧编辑组名、自动关闭（分钟，留空=跟随全局）。＋/− 增删组。
- **② 组内网址**：**未在上方选中组时，这一整块置灰不可编辑**；选中一个组后才可增删/改该组的名称与 URL。
- **③ 全局快捷键**：表格里每条 = 一个“功能 + 按键”。点**＋**添加、选中后用下方或右侧的功能下拉 + **点按钮录按键**（Esc 取消、清除）。功能见上方快捷键表。
- **底部**：全局自动关闭默认分钟数 + 语义说明；导入 / 导出 / 恢复默认 / 取消 / 保存。
- 快捷键冲突会拦截保存并提示。

## 🔁 从旧版本升级

## ❓ FAQ

**为什么用组而不是每个网址一个窗？**
一组一窗、组内 D/E 切站，是“随用随走”最轻的形态：不用开一堆窗口，快捷键就两个方向键，切到哪站自动带出它自己的登录态。

**切站会不会掉登录？**
不会，组内不同网址各自保存 Cookie，互相独立。

**为什么之前按住某些键没反应？**
全局快捷键需要「辅助功能」权限；同时 ⌥⌘D 是系统“隐藏 Dock”的快捷键，本工具会接管——想还给 Dock 可在设置里把 ⌥⌘D 动作设为“无动作”。

**它能放多少个组 / 网址？**
无硬限制；但同一时间默认只显示一个组的悬浮窗（保持干净），需要多开用右键→「显示全部组」。

**B 站提示“浏览器版本过低”？** 内置了较新的 Safari 用户代理（User-Agent），多数站点都会放行；如个别站点仍提示，告诉我域名我再针对性处理。

**B 站点视频/动态进不去？** 那些是“新标签页（target=_blank）”链接，现在会在当前浮窗里直接打开。若某类链接仍失败，把链接类型告诉我。

**B 站横屏适配差？** 用 ⌘+ / ⌘- 缩放当前页面到合适大小即可；需要固定某档缩放的“记住每站缩放”也可以再做。
