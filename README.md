# 在线 AI 悬浮窗（AIFloatWindow）

> 一个免费的 macOS 原生悬浮窗小工具：按一下快捷键，浮在顶层的小窗口呼之即来，里面直接打开 **豆包 / DeepSeek / 任意网站** 的网页版 AI。支持**多个浮窗**、每个浮窗独立网址/快捷键/自动隐藏，随用随走。
>
> 完全开源、无需登录账号、不收集任何数据。不依赖 Hammerspoon / Electron 等第三方运行时——纯 Swift + AppKit + WKWebView 原生实现。

## ✨ 特性

- 🪟 **多浮窗**：默认带「豆包」和「DeepSeek」两个浮窗，可任意增删；每个都是独立的悬浮窗，支持**同时只显示一个**或**一键全部摊开**。
- ⌨️ **全局快捷键**：
  - **⌥Space** 显示 / 隐藏当前浮窗
  - **⌥⌘D / ⌥⌘E** 默认=下一个 / 上一个浮窗（可在设置里改成“切到指定浮窗”或“无动作”）
  - **每浮窗可设专属快捷键**（默认无，设置面板里录制）
- ⏱ **自动隐藏**：全局可设（默认 15 分钟），每个浮窗还能单独覆盖；窗口内任何点击/滚动/输入都会续时；设 `0` 表示不自动隐藏。
- 🎛 **设置面板**：状态栏 → 设置…——列表管理浮窗、改网址、录制专属快捷键、启用/停用（停用不建窗口不吃内存）、导入/导出 JSON 配置、一键恢复默认。
- 📐 **记忆位置与尺寸**：每个浮窗记住上次拖到哪、多大，下次原处弹出。
- 🔄 **一键换 AI**：☝ 前面 ⌥⌘D/E 循环或直接切，各站点登录/会话互不干扰。
- 🥤 **轻量**：原生 App，窗口未打开时不占页面进程；不常驻大网页标签。
- 🔔 **常驻状态栏**：无 Dock 图标，菜单里直接选浮窗/全部/设置/退出。

## 🖥 环境要求

- macOS 13.0 或更高（Apple Silicon / Intel 均可）
- Xcode Command Line Tools（仅构建需要）：

```bash
xcode-select --install
```

## 📦 构建 & 安装

```bash
git clone <你的仓库地址> AIFloatWindow
cd AIFloatWindow
./scripts/build.sh            # 构建到 build/在线 AI 悬浮窗.app
./scripts/build.sh install    # 可选：复制到 /Applications 并启登录自启
open "/Applications/在线 AI 悬浮窗.app"
```

> 用 Release 的 `在线-AI-悬浮窗-*.zip`：解压后拖进「应用程序」即可。
> 首次运行已在登录项里注册，开机自动启动。

### 📡 首次运行授权（一次性）

全局快捷键需要「辅助功能」权限（只用于接收你按下的快捷键，不记录任何内容）：

1. 启动后如有弹窗点「打开系统设置」；
2. 在 系统设置 → 隐私与安全性 → 辅助功能 勾选「在线 AI 悬浮窗」；
3. 回到 App，约 2 秒内自动启用快捷键（状态栏图标闪一下 ✓）。

> 未授权前也能用：状态栏菜单照样呼出浮窗、打开设置。

## ⌨️ 快捷键一览

| 快捷键 | 默认功能 | 可改在哪 |
|---|---|---|
| **⌥ Space** | 显示 / 隐藏当前浮窗 | 固定 |
| **⌥⌘ D** | 下一个浮窗 | 设置 → ⌥⌘D 动作 |
| **⌥⌘ E** | 上一个浮窗 | 设置 → ⌥⌘E 动作 |
| **（每浮窗专属）** | 呼出该浮窗 | 设置 → 选中浮窗 → 自定义快捷键 |

> ⌥⌘D 是 macOS 默认「自动隐藏 Dock」的快捷键，本工具会接管；如想用回 Dock 那条，可在设置里把 ⌥⌘D 动作改为「无动作」。

## 🎛 设置面板

状态栏图标 → **设置…**：

- **悬浮窗列表**：＋/－增删；勾选某行“开”列可启用/停用（停用即不再建窗口、不占内存）。
- **选中某个浮窗后**：
  - 名称、网址（随意改成任何网站）
  - 自动隐藏（分钟）——留空＝跟随全局；0＝不自动隐藏
  - 自定义快捷键——点按钮后直接按新组合（Esc 取消），「清除」可移除
- **全局**：
  - 自动隐藏（分钟）
  - ⌥⌘D 动作、⌥⌘E 动作：下一个 / 上一个浮窗 / 切到指定浮窗 / 无动作
- **导出… / 导入…**：把整套配置存成 JSON 或从 JSON 恢复（换机、分享配置）。
- **恢复默认**：回到豆包 + DeepSeek 两个默认浮窗。
- 如两个地方撞了同一组快捷键，保存时会提示冲突并阻止。

## 🛠 配置存储

所有配置存在 UserDefaults（bundle id `dev.miaoartist.aifloatwindow`），键 `AppSettings` 内是一份 JSON。可用下面命令备份/查看：

```bash
defaults read dev.miaoartist.aifloatwindow AppSettings
```

不建议手改这个键；请用设置面板或“导出/导入”。

## ❓ FAQ

**为什么不用浏览器标签页 / Hammerspoon？**
浏览器：一个网页一个标签、重且不好呼出；Hammerspoon：好用但要额外装脚本解释器、窗口样式受限。本工具原生、轻量、自带设置面板，一个包搞定。

**换浮窗会不会要重新登录？**
不会。每个浮窗是独立 WKWebView，Cookie 各自保存；换浮窗 = 换一个独立网页，登录态互不影响。

**为什么切换时其它浮窗会收起来？**
默认“同时只显示一个”，切换=把目标带到最前并把别的收起（干净）。要同时看多个用状态栏→「显示全部浮窗」。

**停用某个浮窗后，它的自定义数据会丢吗？**
不会，只在“停用”时不建窗口；改回“启用”后仍在原来位置、保持登录态。

**它和原来的 Hammerspoon 悬浮窗冲突吗？**
这个 App 的目的就是替代它：全新版本已安装到 /Applications，并已停掉 Hammerspoon、移除其登录自启。日后想恢复 Hammerspoon 随时可以。
