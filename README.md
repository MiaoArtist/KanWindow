# 在线 AI 悬浮窗（AIFloatWindow）

> 一个免费的 macOS 原生悬浮窗小工具：**多组网址**，每组一个悬浮窗，组内塞任意多个网站（豆包 / DeepSeek / ChatGPT Web / 任何网页），**⌥⌘D/E 一键在组内切站**。顶栏点一下即呼出，随用随走。
>
> 完全开源、无需登录、不收集数据。不依赖 Hammerspoon / Electron —— 纯 Swift + AppKit + WKWebView 原生实现。

## 🪟 分组机制（核心）

- **网址组**：一个组 = 一个悬浮窗。组里放**多个网址**。
- 打开某个组（用它的专属快捷键 / 顶栏菜单 / ⌥Space）→ 呼出该组的悬浮窗。
- 在组内，用 **⌥⌘D（下一个） / ⌥⌘E（上一个）** 在组内各网址间来回切，窗口标题会显示「组名 · 站点名」，各站登录/会话互不影响。
- 默认配置：一个「AI 助手」组，内含豆包、DeepSeek 两个网址 —— 装完就能 D/E 换着用。

## ⌨️ 快捷键

| 按键 | 作用 | 怎么改 |
|---|---|---|
| **顶栏左键单击** | 呼出 / 收起当前组悬浮窗 | 固定 |
| **⌥ Space** | 呼出 / 收起当前组悬浮窗 | 固定 |
| **⌥⌘ D / ⌥⌘ E** | 组内下一个 / 上一个网址 | 设置 → 全局 |
| **组专属快捷键**（默认无） | 直接呼出该组 | 设置 → 选中组 → 呼出快捷键 |
| **⌘ ,** | 打开设置（窗口内按） | 固定 |
| **⌘C / ⌘V / ⌘X / ⌘A** | 浮窗文本框复制/粘贴/剪切/全选 | 已内置编辑菜单 |

> 状态栏：**左键** = 呼出弹窗；**右键** = 菜单（各组、显示全部组、隐藏全部组、设置、退出）。

## ✨ 其它特性

- ⏱ **自动隐藏**：全局默认 15 分钟，每组可单独覆盖；窗口内任何点击/滚动/输入续时；0 = 不自动隐藏。
- 🎛 **设置面板**（状态栏右键 → 设置 或窗口内 ⌘,）：增删组、给组加/删网址、改任意网址、录组快捷键、启用/停用组（停用不建窗口不吃内存）、导出/导入 JSON、恢复默认。
- 📐 **记忆位置与尺寸**：每组独立记住上次拖到哪、多大；组内自动记住停在哪一站，重开回到原站。
- 📋 **粘贴可用**：内置标准「编辑」菜单，WebView 文本框 ⌘V 正常。
- 🥤 **轻量**：原生 App；组未打开不占网页进程。
- 🔔 **常驻状态栏**：无 Dock 图标。

## 🖥 环境要求

- macOS 13.0+（Apple Silicon / Intel 均可）
- Xcode Command Line Tools（构建需要）：
```bash
xcode-select --install
```

## 📦 构建 & 安装

```bash
git clone <你的仓库地址> AIFloatWindow
cd AIFloatWindow
./scripts/build.sh            # 构建到 build/在线 AI 悬浮窗.app
./scripts/build.sh install    # 复制到 /Applications
open "/Applications/在线 AI 悬浮窗.app"
```

发布包：`在线-AI-悬浮窗-*.zip`，解压拖进「应用程序」即可。

### 📡 首次授权（一次性）

全局快捷键需要「辅助功能」权限：
1. 弹窗里点「打开系统设置」→ 隐私与安全性 → 辅助功能；
2. 勾选「在线 AI 悬浮窗」；约 2 秒后自动启用（状态栏图标闪 ✓）。
> 未授权也能用：点顶栏图标或右键菜单都能呼出浮窗。

## 🎛 设置面板速览

- **网址组**：左列表勾选可启用/停用；右侧编辑组名、自动隐藏（留空=全局）、呼出快捷键（点按钮按新组合、Esc 取消/清除）。
- **组内网址**：给当前选中的组增删网址、改名称和 URL。
- **全局**：自动隐藏默认分钟数、⌥⌘D 动作、⌥⌘E 动作（组内下一个/上一个/切到指定组/无动作）。
- **导出 / 导入 / 恢复默认**：整套配置 JSON 带走。
- 快捷键冲突会拦截保存并提示。

## 🔁 从旧版本升级

v0.1/v0.2 的“浮窗”会自动迁移成“网址组”（每个旧浮窗 → 一个组、内含 1 个网址），设置的 URL、快捷键、位置都保留。之后你可以在设置里往组里继续加网址。

## ❓ FAQ

**为什么用组而不是每个网址一个窗？**
一组一窗、组内 D/E 切站，是“随用随走”最轻的形态：不用开一堆窗口，快捷键就两个方向键，切到哪站自动带出它自己的登录态。

**切站会不会掉登录？**
不会，组内不同网址各自保存 Cookie，互相独立。

**为什么之前按住某些键没反应？**
全局快捷键需要「辅助功能」权限；同时 ⌥⌘D 是系统“隐藏 Dock”的快捷键，本工具会接管——想还给 Dock 可在设置里把 ⌥⌘D 动作设为“无动作”。

**它能放多少个组 / 网址？**
无硬限制；但同一时间默认只显示一个组的悬浮窗（保持干净），需要多开用右键→「显示全部组」。
